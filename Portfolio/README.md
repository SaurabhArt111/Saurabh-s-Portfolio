# Saurabh Portfolio

React + Vite portfolio starter of Saurabh Maurya.

## Run
npm install
npm run dev

## Build
npm run build

## Project data
Edit `src/data/projects.json` to add/edit/reorder projects, GitHub URLs, live URLs, and presentation metadata.

## Live previews
Projects with a `live` URL show an iframe preview in the project modal. Some sites block iframe embedding; the modal also provides an external link fallback.
